# 🐸 Lily Leap

A cozy, pastel browser platformer. Guide a tiny frog across floating lily pads, catch fireflies, and avoid falling into the pond!

## Play
Once GitHub Pages is enabled, visit **https://rianamalhotra.github.io/Lily-Leap/**.

## Controls
- **← / →** or **A / D**: move
- **Space / ↑ / W**: jump
- On mobile, use the on-screen controls
- Press **Enter** to restart after a splash

## Features
- Responsive HTML5 Canvas game, no build tools required
- Side-scrolling pond with procedurally generated lily pads
- Sinking platforms and glowing fireflies
- Score counter and locally saved personal best
- Keyboard and touch controls

## Run locally
Open `index.html` in your browser.

## Tech
HTML, CSS, vanilla JavaScript, HTML5 Canvas.

## Deployment
In GitHub: **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save**.

Made for fun, learning, and little frogs. 🌿
